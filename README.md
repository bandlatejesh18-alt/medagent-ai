# MedAgent AI

A Multimodal Multi-Agent Medical Learning Platform.

## Features

- AI Medical Tutor
- Medical Research Assistant
- Retrieval-Augmented Generation (RAG)
- Medical Image Understanding
- Clinical Case Simulation
- Medical Quiz Generation
- Evidence Verification

## Technology Stack

- Python
- LangChain
- LangGraph
- FastAPI
- Streamlit
- Qdrant
- AWS
